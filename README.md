# Uang Kas Kelas — Android/PWA

Aplikasi kas kelas yang bisa dipakai di HP Android melalui Chrome dan dapat dipasang ke layar utama (Add to Home screen).

## Fitur
- Daftar siswa
- Pemasukan
- Pengeluaran
- Dashboard saldo
- Rekap berdasarkan periode
- Simpan rekap sebagai PDF
- Bagikan rekap melalui WhatsApp / menu Share Android
- Data tersimpan lokal di perangkat (offline)

## Cara menjalankan di Android
1. Upload folder ini ke hosting HTTPS (misalnya GitHub Pages, Netlify, Vercel, atau hosting sekolah).
2. Buka alamatnya di Chrome Android.
3. Pilih menu Chrome → **Tambahkan ke layar utama / Install app**.
4. Aplikasi dapat dipakai seperti aplikasi Android.

Catatan: versi ini adalah PWA sehingga tidak memerlukan Play Store. Untuk APK native, project ini dapat dikonversi ke WebView/Capacitor pada tahap berikutnya.
